# Imagens do site

| Pasta      | Conteúdo                                                        |
|------------|-----------------------------------------------------------------|
| `logo/`    | Logo oficial. `logo-original.jpg` é o arquivo fornecido, sem edição; `logo-emblema.jpg` é um recorte sem a margem verde; `favicon.png` é uma versão reduzida. |
| `pratos/`  | Fotos reais dos pratos (também a foto do hero).                 |
| `galeria/` | Fotos reais de carnes, produtos e ambiente.                     |

Use apenas fotos reais do restaurante. Depois de adicionar um arquivo, registre-o em
`src/config/images.js` e rode `npm run check:images` para confirmar que todos os caminhos existem.
